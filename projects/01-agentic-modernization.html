01 專案背景與核心挑戰 (Context & Problem)

台積電內部的 Early Prewarning 製程交期系統 已穩定運行超過 10 年，底層採用早期的 GWT（Google Web Toolkit）與 EJB（Enterprise JavaBeans）架構。隨著業務規模與即時性需求爆發，系統亟需重構成現代化的前後端分離架構（Next.js + Spring Boot）。

在過往的重構過程中，工程團隊面臨兩大瓶頸：

  • 舊系統程式碼極其龐雜且關聯複雜：傳統人工逐行研讀 GWT/EJB 邏輯費時費力，單一介面翻新平均需耗時 20 天。
  • 通用 AI 生成品質不穩定且提詞冗餘：工程師直接與 AI Agent 對話時，AI 缺乏新系統整體架構上下文，經常產生邏輯幻覺，且工程師需重複輸入大量架構規則與背景提示詞。

02 系統架構與工程設計 (System Architecture)

為了突破瓶頸，我們設計了 Unified Agentic Skill 流程，導入 Git Submodule 將 3 個獨立 Repository（舊框架 ATP-PREWARN、新前端 ESCM-PWFE、新後端 ESCM-PWBE）統整於單一 AI 協作環境中，並建立自動化腳本工作流。

// 跨 Repo Agentic 自動化重構工作流
1. PRD / 舊代碼輸入：輸入需求文字或 ATP-PREWARN 舊代碼檔案
2. /spec-generator 自動解析：派發特定領域 Subagent 分別剖析 GWT 元件與 EJB 邏輯
3. 讀取新框架快取知識庫：自動映射 gwt-to-nextjs.md 與 ejb-to-spring.md 轉換規則
4. 產出標準化 spec.md：包含功能規格書與可執行的 test-strategy.md 測試策略
5. 驅動全端生成：透過 Subagent-Driven Development 進行 Next.js 與 Spring Boot 代碼實作與自動測試

03 關鍵功能與工程亮點 (Key Highlights)

專門化 Subagent 解析機制

設計前端與後端分工的 Subagent Checklists，針對舊框架 GWT 與 EJB 進行語法與邏輯特徵提取，將分析結果格式化為統一欄位的分析報告。

提詞架構優化與架構快取

將 Next.js 元件清單、Spring Boot API 命名慣例、目錄規範預載入腳本，消弭 AI 探索上下文的重複 Prompt，保證生成的代碼符合企業團隊規範。

規格附帶 TDD 測試規劃

透過 output-template.md 與 test-strategy.md，讓產出的 spec.md 同時具備可自動化執行的測試案例規劃，先寫測試再生成代碼。

Git Submodule 跨 Repo 協同

解決前後端分離與舊專案跨 Repo 協同痛點，工程師與 AI 可以在單一整合視窗中執行端到端的重構與驗證。

04 成效指標與量化表現 (Impact & Verification)

  • 大幅縮減介面重構開發週期： 翻新單一大型交期系統介面的工期由原先的 20 天銳減至 5 天，工作效率躍升 75%。
  • 新功能開發極速落地： 成功完成 4 個全新功能介面開發，平均單一介面僅需 2 天即可完成規格產出、前端建構與後端 API 對齊。
  • 工程團隊精力高價值化： 人為介入比例大幅降至 30%，工程師不再深陷於搬移與除錯舊程式碼的泥淖，而是將專注力轉移至高品質的 Code Review 與邊界情境測試。
